Figure. Lightweight hallucination span detection. (a) A source prompt and an LLM answer are pair-tokenized; the prompt is truncated as needed to fit the 4,096-token context. Independent hard- and soft-target ModernBERT-base classifiers produce two-class softmax probabilities for answer tokens. Predeclared ensembles average probabilities only when tokenizers and ordered character offsets agree. The decoder thresholds probabilities, merges gaps measured in tokens, and optionally snaps boundaries to words, returning zero-based, end-exclusive character intervals. The displayed answer is illustrative. (b) Both target variants use answer-only cross-entropy. Hard labels mark token overlap with gold character spans; soft labels mix 0.6 hard labels with 0.4 boundary-shift coverage weighted by word-level Jaccard J + J squared. Target profiles are schematic. The current legacy implementation is not limited to symmetric five-word boundary shifts. (c) Our models use a 10% source-held-out dev split for task-specific decoder tuning. Because published LettuceDetect was trained on all RAGTruth training sources, any ensemble containing it uses fixed baseline decoding; two-fold cross-fitting is restricted to published LettuceDetect alone. Evaluation uses the LettuceDetect-compatible character span F1 and paired 95% bootstrap intervals over test sources. Seeds 43 and 44 and the ensemble configurations are planned or running candidates, not evidence of an accepted improvement. Parameter counts are per ensemble member. The optional character stacker and future span-F1 loss, 8,192-token training, and PsiloQA pretraining are outside this figure.
