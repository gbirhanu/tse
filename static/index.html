Use the API

Send a tweet and its sentiment as JSON. The answer gives the phrase and where it starts and ends in the text.


    
{"selected_text": "Sooo SAD", "start": 0, "end": 8,
 "level1_text": "Sooo SAD", "level2_used": true, "ms": 41, ...}

    
For many tweets at once, post {"items": [...]} to api/extract_batch. All endpoints are listed on the API docs page.
