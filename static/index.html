Use the API

Send a tweet and its sentiment as JSON. The answer gives the phrase, where it starts and ends in the text, and the model's confidence.


    
{"selected_text": "Sooo SAD", "start": 0, "end": 8, "confidence": 0.62, "ms": 41, ...}

    
For many tweets at once, post {"items": [...]} to api/extract_batch. All endpoints are on the API docs page.
